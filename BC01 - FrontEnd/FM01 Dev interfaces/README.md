# FM01 : Développement d'Interfaces Web — TrekHub

Ce module regroupe l'intégration web et le développement frontend du projet TrekHub.

---

## 📁 Structure du Module

- **`src/`** : Code source complet de la plateforme web
  - `index.html` : Page d'accueil responsive (Hero, Directives/Valeurs, Formateurs, CTA)
  - `ateliers.html` : Catalogue complet des ateliers et formations
  - `inscription.html` : Formulaire d'inscription accessible et responsive
  - `css/` : Feuilles de style modulaires (tokens de design, base, responsive layout avec Flexbox / Grid)
  - `js/` : Scripts front-end (navigation mobile, validation)
  - `assets/` : Typographies (Montserrat WOFF2) et images optimisées WebP
- **`docs/`** : Rapports techniques et livrables de TP
  - Audits Lighthouse (Performance, Accessibilité, Bonnes Pratiques, SEO)
  - Livrable TP2 : Textes alternatifs et accessibilité des médias
  - Livrable TP3 : Points de rupture responsive (mobile, tablette, desktop) et captures d'écran
- **`maquettes/`** : Ressources graphiques et maquettes de référence
