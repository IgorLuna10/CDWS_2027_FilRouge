# CDWS 2025-2027 — Projet Fil Rouge : TrekHub

> Projet fil rouge réalisé dans le cadre de la formation **Concepteur Développeur Web et Solutions (CDWS 2025-2027)**.

---

## 🧭 Architecture du Répertoire

Le projet est structuré par **Blocs de Compétences (BC)** et subdivisé en **Fiches/Formations Modules (FM)** :

```text
CDWS_2027_FilRouge/
└── BC01 - FrontEnd/
    ├── FM01 Dev interfaces/
    │   ├── src/                 # Code source du site TrekHub (HTML, CSS, JS, Assets)
    │   ├── docs/                # Rapports d'évaluation, audits, livrables TP
    │   ├── maquettes/           # Maquettes et ressources graphiques
    │   ├── lighthouse-report... # Audit de performance et d'accessibilité
    │   └── README.md
    └── FM02 Ergonomie UX-UI/    # Module UX/UI (en cours)
        └── .gitkeep
```
